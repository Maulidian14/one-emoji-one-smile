## The entry

```
🌻
```

One sunflower. Warm and friendly at first glance, universal across ages
and backgrounds, and chosen rather than default: a sunflower feels picked
for the moment instead of the first smiley that comes to mind, while
staying instantly readable. No words, no caption, no explanation.

## How it works

`main.ts` writes the single emoji to `/output/entry.txt` (falling back to
`entry.txt` beside itself when `/output` is unavailable), after checking
the gate: exactly one emoji, 1–8 characters, not only whitespace.

```sh
node main.ts
```
